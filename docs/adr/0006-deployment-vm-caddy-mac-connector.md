# ADR-0006: 배포 구성 — 클라우드 VM + 도메인, 연결 프로그램은 운영자 Mac

결정일: 2026-09-20. 사용자 확정. 구체적인 VM 제공자·도메인은 아직 지정하지 않았다.

**결정**:

- 중앙 웹/API, 중앙 워커, 진단 API, 진단 워커는 리눅스 VM 한 대에서 systemd 서비스 4개로 돌린다. 도메인을 붙이고 Caddy가 HTTPS 인증서를 자동 발급한다. 진단 API는 VM 내부(localhost)에만 열고 외부에 노출하지 않는다.
- 로컬 연결 프로그램과 Codex, 데모 저장소는 운영자 Mac에서 돌린다. launchd로 자동 재시작한다.
- Mac이 꺼지면 웹과 진단(A)은 계속 동작하고, 코드 수정(B)은 "연결 끊김·대기"로 표시된다. 시작했다고 표시하지 않는다.
- 심사 기간 전체의 OpenAI 호출 총액 상한은 US$30이다. 진단 서비스가 사용 토큰으로 누적 비용을 추정해 90%에서 새 진단 접수를 멈춘다.

**이유**: 심사자는 로그인 없이 2주 동안 접속하므로 웹은 운영자 Mac의 전원·네트워크와 분리돼야 한다. Codex 로그인과 저장소는 Mac에 있어 B는 Mac에서만 실행할 수 있다. 사용자는 Mac 상시 가동을 보장하지 못한다고 밝혔으므로, 오프라인을 정상 상태의 하나로 설계한다.

**트레이드오프**: VM·도메인 준비와 배포 절차가 필요하다. Mac 오프라인 동안 심사자는 B의 실시간 실행을 보지 못한다. 진단 API를 localhost에만 두므로 "외부 주소로 등록하는 API 에이전트"는 데모에서 같은 VM 안의 주소로만 시연한다.
