# ADR-0004: 중앙 서비스는 규칙 기반 — 자동 선택·완료 기준 제안에 LLM 미사용

결정일: 2026-09-20. 사용자 확정.

**결정**: 중앙 웹/API와 실행 조정 워커는 모델을 호출하지 않는다. 자동 선택은 업무의 요구 능력(코드 + 범위)과 에이전트 등록 능력의 명시적 비교로, 완료 기준 제안은 업무 종류별 템플릿으로 처리한다. 첫 구현의 능력 코드는 `operations.diagnose`와 `code.modify` 둘뿐이며 범용 선택 알고리즘을 만들지 않는다. LLM 호출은 진단 데모 서비스(ADR-0003)에만 있다.

**이유**: 무로그인 심사자마다 중앙에서 모델을 호출하면 비용·지연·검증 부담이 생긴다. 데모의 선택 대상은 두 에이전트이고, 능력 코드·범위 일치만으로 선택 이유를 정확히 표시할 수 있다. 판정에 쓰는 정보가 구조화돼 있어 테스트로 검증할 수 있다.

**트레이드오프**: 자유 문장으로 적은 업무 요청에서 요구 능력을 추론하지 못한다. 첫 구현에서는 등록 화면이 요구 능력을 구조화된 항목으로 받고, 데모 업무는 미리 채운 값을 쓴다. 이후 중앙에 모델 기반 제안을 추가하려면 새 ADR로 결정한다.
