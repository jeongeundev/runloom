# ADR-0005: 접근 모델 — 익명 심사자 세션과 운영자 토큰

결정일: 2026-09-20. 사용자 확정.

**결정**:

- 심사자는 로그인 없이 접속한다. 첫 방문에 서버가 서명된 세션 쿠키를 발급하고, 그 세션이 자기 워크스페이스(업무·실행·산출물)를 소유한다. 다른 세션의 업무는 보이지 않는다.
- 운영자 소유로 등록된 데모 에이전트(로컬 Codex 1개, 진단 API 1개)는 모든 세션에 사용 허용된다.
- 에이전트 등록·수정·삭제, 연결 코드 발급·취소, 기준 브랜치 병합은 운영자 전용이다. 운영자는 환경변수의 운영자 토큰(`OPERATOR_TOKEN`)을 입력해 운영자 화면을 연다. 심사자는 등록된 에이전트의 이름·능력·연결 상태를 읽기 전용으로 본다.
- 심사자는 B 결과를 검토 승인까지 할 수 있고, 병합은 "운영자 확인 대기"로 표시된다. 데모 저장소의 기준 커밋은 심사 기간 동안 고정한다.

**이유**: 공모전 규정상 심사자는 무로그인이어야 하고, 동시에 여러 심사자가 들어와도 서로의 업무·검토가 섞이면 안 된다. 등록·병합은 운영자 컴퓨터와 데모 저장소를 바꾸는 동작이라 익명 사용자에게 열 수 없다. 등록 화면을 웹에 두면 "자동 파악 → 확인·수정" 등록 경험이 제품에 남아 영상·실연으로 보여줄 수 있다.

**트레이드오프**: 세션 쿠키를 지우면 자기 업무를 다시 찾을 수 없다(데모에서 허용). 심사자는 병합 단계를 직접 누르지 못한다. 팀·조직 권한 모델은 이 결정에 포함되지 않으며 후속 ADR 대상이다.
