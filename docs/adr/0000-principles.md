# 프로젝트 원칙과 제약

갱신일: 2026-09-20. 아래는 개별 ADR과 구현 판단의 기준이다. 사용자 합의 사항이며, 바꾸려면 이 파일을 고친다.

## 원칙

- 이미 있는 에이전트를 재사용한다. 사용자에게 연결 코드 작성이나 기존 설정 재구성을 요구하지 않는다. 새 에이전트 생성은 첫 범위가 아니다.
- 상태는 증거로만 바꾼다. 접수·시작·결과·완료를 구분하고, 모델의 "완료했다" 응답이나 프로세스 종료 코드만으로 완료 처리하지 않는다.
- 같은 이벤트가 두 번 와도 실행은 한 번이다. 시작 여부를 모르면 재실행하지 않고 확인 필요로 둔다.
- 권한은 최소로 준다. 사내 자료 전체 접근 권한을 개인 에이전트에 자동 부여하지 않고, 기준 브랜치 병합은 사용자 확인 후에만 한다.
- 데모는 실제로 동작해야 한다. 고정 답변 재생으로 진단·수정을 대체하지 않으며, 가상 데이터를 실제 기업 사례로 소개하지 않는다.
- 첫 범위는 A → B 한 단계다. n8n·A2A·MCP·OpenArchive 등 필수가 아닌 의존은 첫 구현에서 제외한다.
- 새 기능은 테스트를 먼저 쓴다 (루트 AGENTS.md의 TDD 규칙).

## 공모전 제약 — 원티드 AI Championship 2026

사용자가 2026-09-20 적용을 확인했다. 모든 배포·시연 설계는 이 제약을 전제한다.

- 제출 마감 2026-09-20, 심사 기간 2026-09-21 ~ 2026-10-05. 심사 기간 동안 서비스가 접속 가능한 상태여야 한다.
- 심사자는 별도 로그인 없이 웹에서 핵심 기능을 체험한다. 설치 파일·다운로드 방식은 불가하다.
- 따라서 심사자 기기에 연결 프로그램 설치를 요구할 수 없다. 로컬 연결 프로그램은 운영자가 준비한 환경에서 상시 실행하고, 심사자는 웹에서 그 결과를 본다. 등록 절차 자체는 실연 또는 기록 영상으로 증명한다.
