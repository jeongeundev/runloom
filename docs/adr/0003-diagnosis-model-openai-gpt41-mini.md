# ADR-0003: 진단 모델 — OpenAI GPT-4.1

결정일: 2026-09-20. **사용자 확정** (같은 날 `gpt-4.1-mini` 작업 가정으로 시작해 네 차례 평가 뒤 `gpt-4.1` 로 확정). 파일 이름은 링크 안정을 위해 유지한다.

**결정**: 진단 데모 서비스는 OpenAI Responses API 를 호출하고 모델은 `gpt-4.1-2025-04-14` 다. 읽기 전용 조회 도구 4개는 function calling 으로, 진단 결과 봉투는 structured outputs 로 받는다. 전체 하루 진단 상한 `DIAG_GLOBAL_DAILY` 는 60 → **36** 으로 낮춘다 (심사 15일 × 36회 × US$0.049 ≈ US$26.5 로 총액 US$30·90% 정지선 안).

**이유**: 같은 하네스(5사례 × 3회, 프롬프트 v3·도구 v2)에서 `gpt-4.1-mini` 는 네 번의 평가(v1 2회·v2·v3)에서 정상 사례 `normal` 을 한 번도 3/3 으로 넘기지 못했고, `gpt-4.1` 은 `normal` 3/3·계약 거부 0·도구 인자 오기 0 으로 ARCHITECTURE 통과 기준을 충족했다 ([DIAG_EVAL](../DIAG_EVAL.md)). 시연의 핵심인 "A 자동 완료 → B 자동 착수" 는 `normal` 이 안정적이어야 성립한다. 키·계정 사용 가능·예산은 확인됐다.

**트레이드오프**: 진단 1회 비용 US$0.049(mini 의 5.7배)·42초(3배). 하루 상한을 36 으로 낮춰 총액 안에 두므로 심사 트래픽이 몰리면 그날 진단이 429 로 막힌다 — DEPLOY 9절 `/budget` 점검으로 소진 속도를 보고 조정한다. 자료 누락·충돌 사례에서 모델이 스스로 보류하는 비율은 gpt-4.1 도 2/12 이며, 잘못된 인계는 검증기(`verify_diagnosis`)가 막는다 — 모델 교체가 검증기를 대체하지 않는다. 자격 증명은 진단 서비스에만 두며 로컬 Codex 로그인으로 대체하지 않는다. 모델을 다시 바꾸면 같은 하네스로 재평가한다.

**이력**: 작업 가정 `gpt-4.1-mini-2025-04-14` (2026-09-20 오전) → 평가 4회 미달 → `gpt-4.1` 비교 평가(phase 2-model-compare) → 확정. 단가는 gpt-4.1 입력 US$2.00 / 출력 US$8.00 (백만 토큰당, 2026-09-20 확인).
