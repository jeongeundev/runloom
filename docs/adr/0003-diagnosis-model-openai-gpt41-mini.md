# ADR-0003: 진단 모델 — OpenAI GPT-4.1 mini (작업 가정)

결정일: 2026-09-20. **상태: 작업 가정.** 사용자 확정이 아니며 아래 확정 조건을 통과해야 확정으로 바꾼다.

**결정(가정)**: 진단 데모 서비스는 OpenAI Responses API를 호출하고 첫 평가 모델은 `gpt-4.1-mini-2025-04-14`다. 읽기 전용 조회 도구 4개는 function calling으로, 진단 결과 봉투는 structured outputs로 받는다.

**이유**: 공식 문서에서 Responses API·function calling·structured outputs와 해당 스냅샷을 확인했다. 작은 자료와 도구 4개로 구성된 데모에서 먼저 평가할 후보이며, 최신·최고 성능 모델이라는 주장은 아니다.

**확정 조건**: 진단 API 구현 step을 시작하기 전에 API 키, 계정의 API 사용 가능 여부, 호출 예산 상한을 확인한다. 확인 전에는 해당 step을 `blocked`로 두고 유료 호출을 하지 않는다. 확인에 실패하면 다른 제공자를 새 ADR로 결정하고 이 파일을 `docs/adr/superseded/`로 옮긴다.

**트레이드오프**: 자격 증명은 진단 서비스에만 두며 로컬 Codex 로그인으로 대체하지 않는다. 유료 호출 비용이 발생한다. 모델을 바꾸면 프롬프트·도구 계약 평가를 다시 해야 한다.
