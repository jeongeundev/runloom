# ADR-0002: 서버·화면·저장 스택

결정일: 2026-09-20. 사용자 확정.

**결정**:

| 영역 | 선택 |
|---|---|
| 언어 | Python 3.13 계열 |
| 웹/API | FastAPI + Uvicorn |
| 화면 | Jinja2 서버 렌더링 + CSS + 소량의 브라우저 JavaScript(상태 영역 폴링) |
| 입출력 계약 | Pydantic v2 (API 경계에서 검증, JSON Schema 생성) |
| 영속 저장 | 표준 `sqlite3` + 명시적 SQL, 비공개 산출물 디렉터리 |
| HTTP 클라이언트 | HTTPX |
| 테스트 | pytest |

중앙 웹/API, 중앙 워커, 진단 API, 진단 워커, 로컬 연결 프로그램은 하나의 저장소에서 별도 진입점으로 실행한다. 디렉터리 구조는 `docs/ARCHITECTURE.md`의 제안을 따른다.

**이유**: 기존 하네스·훅이 Python/pytest 기반이라 검증 명령을 하나로 유지할 수 있다. 단일 서버·소규모 데모이므로 프런트엔드 빌드 파이프라인·ORM·별도 큐 서비스 없이 시작한다.

**트레이드오프**: SQLite와 로컬 산출물은 단일 지속 실행 서버를 전제하므로 다중 서버·임시 디스크 배포에는 맞지 않는다. 복잡한 흐름 편집기가 필요해지면 React 계열을 재검토한다. 의존 패키지의 정확한 버전은 첫 구현 step에서 설치한 뒤 고정한다. 정적 검사 도구(Ruff)의 채택과 훅 연동은 AGENTS.md 명령을 확정할 때 함께 정한다.
