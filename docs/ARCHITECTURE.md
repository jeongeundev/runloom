# 아키텍처

## 디렉토리 구조

역할 슬롯을 실제 경로로 채운다. 스택마다 이름이 다르므로 경로가 아니라 **역할**을 기준으로 매핑한다.
`docs/presets/` 에 해당 스택 프리셋이 있으면 그 트리를 그대로 복사해 온다.

```
{루트}/
├── {진입점}        # 요청·명령이 처음 들어오는 곳 (라우트 핸들러, CLI 엔트리, 컨슈머)
├── {도메인 로직}   # 비즈니스 규칙. 프레임워크에 의존하지 않는 계층
├── {타입·스키마}   # 타입 정의, 검증 스키마, 데이터 모델
├── {외부 연동}     # 외부 API·DB·큐 래퍼. 여기 밖에서 직접 호출하지 않는다
└── {공용 유틸}     # 순수 함수 헬퍼
```

## 외부 의존

이 시스템이 무엇과 붙는지 명시한다. 여기 없는 외부 서비스는 임의로 도입하지 않는다.

| 대상 | 용도 | 접근 경로 |
|------|------|-----------|
| {예: 외부 결제 API} | {결제 승인} | {외부 연동 계층에서만} |
| {예: PostgreSQL} | {영속성} | {리포지토리 계층에서만} |
